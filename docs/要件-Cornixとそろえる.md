## 2. 実機の違い（実測）

### キーの数と並び

| | Cornix LP | roBa |
|---|---|---|
| 合計 | 48キー | **43キー＋トラックボール** |
| 左半分 | 24（6列×3段＋下段6） | 23（**5列**×3段＋内側2＋下段6） |
| 右半分 | 24（6列×3段＋下段6） | **20**（5列×3段＋内側2＋下段3） |
| ファームウェア | Vial（ブラウザで即書き換え） | ZMK。⭕ **ZMK Studio 有効**（ブラウザで即書き換え可） |

### 🔴 決定的な違い：右手の下段がトラックボールに取られている

- **Cornix の右下段は6キー**（`日本語` `機能面` `Enter` ＋ `←` `↓` `→`）
- **roBa の右下段は3キーだけ**。残りの場所にトラックボールがある

→ **Cornix がベース面に持っている矢印キーを、roBa は同じ場所に置けない。**

### そのほかの違い

- Cornix には**一番外側の列**（`Tab` `Ctrl` `Shift`）がある。**roBa には無い**
- roBa には**内側に追加の列**がある（人差し指を内へ伸ばす位置・左右2つずつ）
- roBa は右手側にトラックボール（動かすと自動でマウス面へ／`I` を押しながらでスクロール）

## 3. 🔴 いまの roBa で壊れているもの

**日本語と英語の切り替えが効いていない。** Cornix とまったく同じ原因。

現行は親指に `INT_MUHENKAN` / `INT_HENKAN` を割り当てているが、
**Windows がこのPCのキーボードを英語(101/102)として扱っている**ため、この信号は届かない。

→ **`&kp LANG2`（英語）/ `&kp LANG1`（日本語）に差し替えれば直る**（Cornix で実証済み）。

⚠ 組み合わせ押し（コンボ）にも `INT_MUHENKAN` が入っている（キー位置 11+10）。ここも同時に直す。

## 4. そろえられるもの / そろえられないもの

### ⭕ そろえられる（左手はほぼ完全）

| 項目 | 備考 |
|---|---|
| **文字キー全部** | QWERTY・ZXCV・NM,./ — もともと同じ |
| **左手の一番下の段6つ** | `Win` `Alt` ＋ 親指3つ（`Space` / 数字記号面 / `英語`）を同じ並びにできる |
| **数字・記号の面** | 🔴 **ほぼ完全に一致させられる**（下記） |
| **面の呼び出し位置** | 左親指＝数字記号、右親指＝機能。同じ |
| **日本語・英語の切替** | 左親指の一番内側＝英語、右親指の一番内側＝日本語 |

**数字・記号の面がぴったり合う理由**: Cornix は左の上段に `1〜5`、その下に `! @ # $ %`、
さらに下に `^ & * ( )` を置いている。**roBa の1段は5キーなので、この5つずつがそのまま入る**。
右手も `6〜0` / `- = [ ] '` / `: " ? + \` がそのまま入る。

### ❌ そろえられない

| 項目 | 理由 | どうするか |
|---|---|---|
| **矢印キー** | roBa の右下段にキーが無い（トラックボール） | roBa は面の中に置く。⭕ 代わりにトラックボールがある |
| **`Tab` `Ctrl` `Shift`** | roBa に一番外側の列が無い | 内側の追加キーか下段へ回す |
| **`BackSpace` `Enter`** | roBa に外側の列が無い | 親指か内側の追加キーへ |

## 5. 🔴 決めること（ユーザー判断）

**Cornix 側も動かして両方を歩み寄らせるか、Cornix はそのままにして roBa だけ寄せるか。**

いま Cornix の左下段の一番外は `Esc`、roBa の同じ位置は `Ctrl`。
交互に使うと**同じ場所を押して違うものが出る**ので、どちらかにそろえたい。

| 案 | 内容 | 代償 |
|---|---|---|
| **A. roBa だけ寄せる** | Cornix は一切触らない | roBa 側で無理が出る箇所が残る |
| **B. 両方を歩み寄らせる** | Cornix の一部（下段の外側など）も動かす | Cornix の指の記憶をやり直す箇所が出る |

⚠ Cornix はまだ**ゲーム面が未検証**なので、どのみち触る可能性はある。

## 6. 面の数を減らす

現行 roBa は7つ。うち**マウス面とスクロール面はトラックボールが自動で切り替える**ので、
覚える対象ではない。**覚えるのは 通常・数字記号・機能・ゲーム2つの5つ**にそろえる（Cornix と同数）。

- 現行の「矢印面」は**機能面に統合**する（Cornix も移動系は機能面にある）
- 現行の「無線・保守面」は**機能面の端**へ（Cornix も機能面の端に無線切替がある）
